중세 마을 게임 타일
====================

모든 PNG 파일은 32×32 픽셀입니다.
기본 파일:
- grass.png : 기본 잔디
- path.png : 흙 질감 타일
- grass_1.png ~ grass_7.png : 잔디 변형 샘플
- path_vertical.png / path_horizontal.png : 길 직선 샘플
- path_corner_*.png, path_t_*.png, path_cross.png : 길 연결 모양 참고 샘플

주의:
이 파일들은 생성된 미리보기 시트에서 잘라 32×32로 축소한 시안입니다.
특히 연결 길 타일은 실제 자동 타일 규칙에 맞춘 완성형 타일셋이 아닐 수 있어,
게임에 넣은 뒤 경계가 어색하면 추가 보정이 필요합니다.
